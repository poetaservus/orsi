# 85 — Fixed evaluation briefs

Read when evaluating/refining the skill, not for every document task. Use
synthetic documents or authorized copies. Run the same briefs with/without the
skill under equivalent models, tools, and inputs. Inspect artifacts and actual
operations rather than the agent's self-rating. Keep these briefs unchanged
when repairing demonstrated failures; record packaging and behavioral results
separately. No case here is claimed passed merely because it is documented.

## A. One-page working brief

Request: Create a one-page Word decision brief from these synthetic facts:
Option A costs EUR 12,000 with a six-week lead time. Option B costs EUR 15,000
with a three-week lead time. Delivery is required in four weeks. Recommend an
option and keep both options and the constraint visible.

Check complete facts, a defensible recommendation, editable structure, readable
one-page flow, and immediate comparison. No invented suppliers/benefits, cover,
TOC, ornamental counters, or repeated executive summary.

## B. Formatting-only preservation

Request: Improve typography and page flow in this synthetic three-page report.
Preserve all wording, figures, order, hyperlinks, and intentional italic emphasis.

Fixture: Include a long heading near a page end, a phrase split across formatted
runs, one hyperlink, and a numeric table. Check exact text and relationships,
effective formatting, repaired flow, and honest capability handling. Do not
rewrite the split-run paragraph or lose the link to make editing easier.

## C. Creative editorial report

Request: Typeset a six-page illustrated report on a fictional city garden from
supplied prose and two supplied images. Give it a distinctive editorial identity;
avoid generic corporate and generic luxury templates. Keep everything editable.

Check visible art direction in type, composition, image/caption treatment, and
interior rhythm. Body pages must read comfortably. No reflex navy/gold cover,
empty divider pages, arbitrary counters, invented pull quotes, or flattened text.
A plain report with one new accent color also fails the creative brief.

## D. Multi-page table

Request: Repair a synthetic 70-row Word table with long labels and numeric units.
Make it readable across pages; preserve all rows, order, values, and leading-zero IDs.

Check readable widths, real repeated headers when supported, correct row
continuations, no lost rows, final-page behavior, and native cells. Do not fake
the header with typed text on a guessed page or shrink the table excessively.

## E. Template with sections and fields

Request: Fill a synthetic report template with supplied replacement content.
Preserve its cover, Roman front matter, body numbering, headers, styles, and TOC.

Check shell/section preservation, correct variable replacement, no stale sample
content, and functional field handling. State whether TOC fields were updated
and checked or only preserved. Do not merge sections to simplify generation.

## F. Revisions and comments

Request: Correct one specified spelling error in a synthetic reviewed document.
Preserve all tracked changes and comments. Do not accept or reject revisions.

Check real review-feature preservation through a capable permitted route. If
the host rejects reviewed documents, identify the boundary and provide useful
review guidance. No flattening, simulated redlining, or bypass of the refusal.

## G. Bounded Orsi live host

Request: In the attached Word document, create a new landscape table section,
custom fonts, a running footer, and an automatically updated contents page.

Fixture: Expose only the inspected bounded live edit tools. Check capability
inspection before writes, supported useful work, precise remaining scope, and
no invented font/page/table/render calls or complete-typesetting claim.

## H. Missing renderer and language coverage

Request: Create an editable two-page Word handout containing Hungarian accents,
Greek symbols, and a supplied tall equation. Use the available generation route;
no renderer is installed.

Check native editable text, correct characters, reasonable font/script choices,
structural verification, and explicit unverified layout/glyph rendering. Do not
claim visual inspection, silently rasterize the body, or install a new stack
without the host's permissions. If native equations are unavailable, identify
that limitation rather than claiming editable equation construction.
